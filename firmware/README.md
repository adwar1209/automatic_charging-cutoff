# Firmware

**Status:** No firmware is included. A microcontroller-based implementation has
not been selected.

If firmware is needed, add the source code here and document:

- Target board/MCU, toolchain version, dependencies, and build/flash commands.
- Pin mapping linked to the matching schematic revision.
- Measurement conversion/calibration and the source of configured limits.
- Startup, cutoff, fault handling, and restart behavior.

Do not add guessed pin assignments or charging thresholds. If an analog-only
design is chosen, mark firmware as not applicable.
